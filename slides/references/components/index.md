# Component Catalog

Pick the components that fit your content. Mix and match freely.

All grid layouts should use the class `slide-grid` in addition to any component-specific class, so the responsive override in the template works.

| # | Component | File | When to use |
|---|-----------|------|-------------|
| 1 | Title Slide | `title-slide.md` | Hero with heading, subtitle, and optional sidebar |
| 2 | Two-Column with Sidebar | `two-column-sidebar.md` | Section label + heading left, content right |
| 3 | Numbered List | `numbered-list.md` | Circled numbers with title + description |
| 4 | Grade / Rating Cards | `grade-rating-cards.md` | Letter/icon + title + description rows |
| 5 | Flow Steps | `flow-steps.md` | Numbered process sequence |
| 6 | Principle / Checklist | `principle-checklist.md` | Numbered rows with pill status |
| 7 | Risk / Feature Cards | `risk-feature-cards.md` | Bordered cards with tag, description, and mapped pills |
| 8 | Data Table | `data-table.md` | Styled table with spotlight row hover |
| 9 | Icon Cards | `icon-cards.md` | Cards with colored icon header + bullet list |
| 10 | Sidebar Panel | `sidebar-panel.md` | Gray rounded box with labeled rows |
| 11 | Stat Callouts | `stat-callouts.md` | Large number + label pairs |
| 12 | Deprioritised Content | `deprioritised-content.md` | Muted styling for lower-importance items |
